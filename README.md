# JAXO

> **Your terminal. Your AI. Your workflow.**

JAXO is a personal AI assistant being built for the terminal. The goal is a clean, keyboard-first chat experience that can help with everyday questions, writing, coding, and developer workflows.

## Project status

🚧 **Early development — not yet a stable release.**

This repository is being prepared for public contributors and users. The documentation is being added first; the complete Python application source still needs to be published here before the install-and-run instructions can work end to end.

## Planned capabilities

- General-purpose AI chat
- OpenRouter model support
- Developer and coding assistance
- GitHub repository workflows
- Local project navigation
- A compact terminal interface

Features may change as development continues. Browser automation and unrestricted computer control are not currently available.

## Configuration and API keys

JAXO is designed to use an API provider such as OpenRouter. You will need your own provider API key when the application source is available.

Never commit your real API key. Keep it in a local `.env` file, and do not share it in screenshots, issues, or chat messages.

## Safety notes

- Review code before running it.
- Do not expose API keys, access tokens, or private repository contents.
- AI-generated commands and code can be wrong; review them before execution.
- GitHub and local-file actions should remain limited and approval-based.
